# Normative connectivity estimation

Estimate normative FDG-PET connectivity using graphical lasso on SUVRs from `controls` and `controls-adni`. Cerebellum and vermis regions are excluded, and each retained region is centered and scaled using the control sample standard deviation.

The process evaluates five-fold cross-validation, AIC, BIC, and extended BIC (EBIC, gamma = 0.5) over a configured regularization grid. EBIC identifies the graph displayed in the connectivity figure. Binary edges correspond to off-diagonal precision entries with absolute values greater than `1e-6`; the diagonal is zero. Graph connectivity is reported for each fitted parameter.

## Requirements

Install the [R packages](../../README.md#r) and provide a SUVR Parquet file generated by [SUVR extraction](../extract_suvrs/README.md).

## Configuration and execution

Edit the configuration block in [`main.R`](main.R):

| Parameter | Description |
| --- | --- |
| `file_path` | SUVR input file, defaulting to `data/processed/suvr/20251130_suvr.parquet`. |
| `output_dir` | Output folder, defaulting to `data/processed/graphical_lasso/test`. |
| `lambda_values` | Regularization parameters to evaluate; the default grid spans `0.001` to `0.9`. |

Paths are relative to the repository root. Update `file_path` to use the filename generated by SUVR extraction, then run:

```bash
Rscript processes/graphical_lasso/main.R
```
