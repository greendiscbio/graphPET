# Individual connectivity matrices

Calculate metabolic co-abnormality for every subject using SUVR deviations from controls. Cerebellum and vermis regions are excluded.

Each pairwise weight is `R[i, u, v] = |z[i, u] + z[i, v]|`. The exported matrices are dense and include diagonal entries. Downstream analyses align the region labels with the normative graph and retain only its edges, excluding the diagonal.

## Requirements

Use the [Python environment](../../README.md#python) and a Parquet file generated by [SUVR extraction](../extract_suvrs/README.md). The normative graph is applied downstream and is not an input to this script.

## Configuration and execution

Edit the configuration block in [`main.py`](main.py):

| Parameter | Description |
| --- | --- |
| `suvr_file` | SUVR filename within `data/processed/suvr`, defaulting to `20251130_suvr.parquet`. |
| `output_directory` | Output folder, defaulting to `data/processed/individual_conn_matrix`. |

Update `suvr_file` to use the filename generated by SUVR extraction. From the repository root, with the Python environment activated, create the configured output folder and run:

```bash
mkdir -p data/processed/individual_conn_matrix
python processes/individual_conn_matrix/main.py
```
